# Peh Yan Bin — Technical Skills Portfolio

A premium, skills-first personal portfolio built with Next.js, React, TypeScript, Tailwind CSS, Framer Motion, Lucide React and Simple Icons via `react-icons`.

## Highlights

- iOS / Apple-inspired glassmorphism and dark graphite visual language
- Floating glass navigation with active-section state
- Full-screen identity hero with uploaded portrait
- Responsive technical stack overview with custom SVG illustrations
- Apple-style sticky cybersecurity capability story
- iOS-style security toolkit grid
- Reverse engineering and malware-analysis feature cards
- Programming cards for Python, C++, C# and web development
- Interactive SVG networking topology with tooltips
- Operating-system and virtualization sections
- Animated neural-network AI visualization
- Interactive orbit capability map
- Skill-connection storytelling
- Custom desktop cursor, magnetic buttons, pointer reflections and reduced-motion support
- No projects section, project cards, case studies, portfolio gallery or skill percentages

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Production build

```bash
npm run build
npm start
```

## Notes

The content is intentionally centered on technical capabilities. The portrait is bundled locally at `public/peh-yan-bin.jpg`, and skill/tool content lives in `lib/skills.ts` for easy maintenance.
